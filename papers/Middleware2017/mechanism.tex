\er{suggested outline}
\begin{itemize}
	\item define the problem: we have a number of broadcast protocols P and nodes can use any of these protocols. Some protocols have only a reactive approach (i.e. their function is called only when an incoming message arrives from the network or when there is a request from the application), while others have a mix of a reactive approach together with a daemon that can initiate actions at predefined times (e.g. to send beacons and form an overlay)
	\item we consider that the network has a simple API (\refalg{network_api}) and that all broadcast protocols also use a common API (\refalg{protocol_api}).
	\item a message is initiated at any node and must reach all the others
	\item assume that any node does not know which protocol its neighbors are running
	\item if a node receives requests (e.g. for overlay construction) that are not for the locally-running protocol, they ignore them (this does not apply to messages carrying a payload)
	\item we want to ensure that the broadcast is complete
	\item show a naive example with an overlay based system and one based on flooding that if each node follows its own protocol only then we have risks of incomplete dissemination
	\item we detail and prove correct in this section an algorithm that ensures protocol interoperability, that is, the broadcast succeeds even if it crosses an arbitrary number of regions using different protocols.
\end{itemize}
