\vicent{
Each node has a local Boolean variable related to the will of swap protocol, we are going to call it from now on swappingWill. Thus, each node checks the information around itself, deciding locally whether it will be good for itself to swap the protocol or not. In affirmative case, the node sets to TRUE the swappingWill variable, adding the swappingWill variable to each message sent and the protocol the node wants to swap.
If a node N2 with the swappingWill variable as TRUE receives a message from node N1 including a swappingWill variable TRUE, then N2 checks if both nodes (N1 and N2) want to swap to the same protocol. In affirmative case, N2 will send a message with the swappingWill variable as TRUE with the same protocol both nodes want to swap. After sending it, N2 will start to swap the protocol. N1 will switch the protocol after receiving the message from N2.
Consequently, the nodes will decide locally if it is good for them to switch the protocol. However, it is collective decision if they will finally change. As a result, one node cannot switch alone to one protocol.
}

\vicent{
Use case:
\begin{enumerate}
\item Node N1, N2 and N3 are running ABBA.
\item Node N1 and N2 want to switch to MPR using the information that is around them. So both set their local swappingWill to TRUE.
\item N1 sends a message saying that it wants to swap (swappingWill = TRUE) and the protocol it wants to swap.
\item N2 receives the message and send a message with to swap (swappingWill = TRUE) and the protocol it wants to swap as well.
\item N2 switch to MPR because it received the messages from N1.
\item N1 switch to MPR because it received the messages from N2.
\end{enumerate}
}
