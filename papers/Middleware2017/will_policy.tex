\subsection{Share Will Switch Policy}
\labsection{policies:SWSP}
Share Will Switch Policy (SWSP) is an adaptation policy based on a local decision and collective protocol switch presented in \refalg{SWSP}.
For this purpose, each node has a local Boolean variable called \textit{willSwitch}.
Thus, each node periodically checks its local estimated density and, in case another protocol is more suitable, \textit{willSwitch} variable of this node is set to TRUE, adding to each message sent the \textit{willSwitch} variable and the protocol the node aims to switch(\textit{pSwitch}).


In case a node with \textit{willSwitch} as TRUE receives a message containing \textit{willSwitch} as TRUE and \textit{pSwitch} in the message equals to \textit{pSwitch} of the node, therefore, this node switches to \textit{pSwitch} protocol and broadcasts a message attaching \textit{willSwitch} as TRUE and \textit{pSwitch}.
After sending the message, the node will set the \textit{willSwitch} as FALSE.

On the other hand, if a node with \textit{willSwitch} as TRUE receives a message using the protocol this node aims to switch, in that case, the node will switch to the desire protocol and will send a message attaching \textit{willSwitch} as TRUE and \textit{pSwitch}.
After sending the message, the node will set the \textit{willSwitch} as FALSE.
