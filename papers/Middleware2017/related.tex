Regarding adaptive-based broadcast algorithms, Hypergossiping~\cite{hypergossiping} is a broadcast strategy protocol designed for MANETs where the authors combine two different protocols: Probabilistic Flooding~\cite{Ni1999} (known as gossiping in the paper) and Hyper-Flooding~\cite{Cheng2005}. 
Hyper-flooding is a mechanism that forces each node to keep a track of its current neighbours. In case the same message is received again and new neighbours have been added between messages, then the node re-broadcasts the message.
%\er{the concept of hyperflooding (actually a DTN-aware flooding) should be detailed, it is not standard.}
Hypergossiping was designed for partitioned networks where partitions of mobile nodes are constantly changing.
Inside each partition, nodes use the Probabilistic Flooding protocol to send and receive messages adapting their local probability of forwarding incoming messages based on the local density of the node.
If two partition joins, the nodes which detect the join will re-broadcast the messages using Hyper-Flooding.
Hypergossiping cannot work with partitions using different protocols and not switch mechanism is developed.

Abdou et al.~\cite{Abdou2012} propose an adaptive broadcasting protocol for MANETs called Smart-Flooding. 
This mechanism utilises the Shadowing Pattern~\cite{Dhoutaut2006}, a propagation model that is a realistic and probabilistic scheme based on outside monitored communications, together with an evolutionary algorithm created by the authors. 
According to this Shadowing Pattern, each node modifies its own local parameters using the evolutionary algorithm and the network density calculated by sending periodically control messages.

Cartigny and Simplot~\cite{ProbFlood} propose probabilistic algorithms for MANETs combining a simple probabilistic algorithm, a distance-based scheme~\cite{Ni1999},

and a neighbour elimination scheme~\cite{Peng2000,Stojmenovic20028} to reduce the number of broadcast messages sent through the network.
In the distance-based scheme a node broadcasts a message only if the distance between itself and the receiver is larger than a specific threshold.
In this work, periodically control messages are sent by the nodes in order to know the number of neighbours around themselves.

Xu and Gerla~\cite{Kaixin2002} describe a heterogeneous routing protocol based on a clustering scheme that allows different MANET broadcasting protocols to work together.
The authors predefine specific nodes to be backbone nodes.
These can communicate among themselves using long distance communications as compared to non-backbone nodes.
Each backbone node creates a cluster with a specific protocol used by the nodes contained in its area.
The nodes, excluding the backbone ones, can move among different backbones areas switching to the correspondent protocol.
Therefore, when a broadcast message is sent, the backbone nodes send the broadcast message among them, and after that, among nodes in their respective cluster areas.
