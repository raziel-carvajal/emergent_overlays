\section{Perspectives}
\label{sec:perspectives}

The experiments presented in Section~\ref{sec:evaluation} show that external parameters such as mobility and density impact the performance of broadcast algorithms.
%
Interestingly, these parameters can be monitored at runtime.
%
For instance, nodes can detects the density in its vicinity by sending control messages or by listening to the traffic.
%
Likewise, mobile devices are equipped with positioning systems and/or accelerometers to sense the movement of nodes.
%


Our next step is using the results of this paper to drive an adaptive overlay for disseminating messages.
%
In our vision, a monitoring process provides data to a management layer that decides which approach a node should use to disseminate messages (e.g., \textit{MPR}, \textit{ABBA}, or \textit{simple flooding}).
%
The main challenge in this case is replacing the algorithm used at runtime without losing any message.
%
Fortunately, most dissemination protocols do not require keeping a complex state on each node.
%
Hence, we think that they are interchangeable while keeping strong guarantees on message delivery.
%
We also see possible having, for instance, an implementation of \textit{ABBA} ``talking'' to \textit{simple flooding} or \textit{MPR} through a translation layers.
