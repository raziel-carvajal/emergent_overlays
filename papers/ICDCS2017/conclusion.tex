\section{Conclusion}
\label{sec:conclusion}

Selecting which is the appropriate broadcast algorithm for a given MANET deployment scenario is a daunting task.
%
The performance of all existing approaches strongly depends on this deployment context.
The context makes hard to find an adequate approach with the right balance between reliability and efficiency.

The main contribution of this work is to provide a comprehensive comparison of
effectiveness of broadcast algorithms for MANETs that helps to take an
informed choice between them based on such target deployment scenarios.

Our study reveals that the best algorithm for a given situation, such as a static network, is not the most appropriate for other situations where there is for instance mobility.
%
More specifically, we have compared in our work five representative algorithms  in different scenarios that we describe in terms of network density and node mobility.
%
The results obtained allow us to identify what characteristics of these approaches are correlated to a certain performance outcome.
%
Using this information, we can identify what are the algorithms that better match the studied deployment scenarios.
