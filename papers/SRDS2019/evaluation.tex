\section{Evaluation}
\label{sec:evaluation}

\textbf{configurations of experiments:}
\begin{enumerate}
	\item communication area with a single PoI
	\begin{itemize}
		\item communication dimensions: 90m x 45m = 4,050$m^{2}$ (min dimensions of soccer field)
		\item PoI dimensions (aprox. a quarter of the hole communication area): 50m x 20m = 1, 250$m^2$
		\item parameters of motion in
		\begin{itemize}
			\item dense area: random between 0 and 1m/s
			\item sparse area: random between 1 and 2m/s
			\item nodes perform levy walks \cite{rhee2011levy} %\textbf{or} nodes follow random-way point approach
			\item nodes moves continuously and every one second the direction of levy walks changes
		\end{itemize}
	\end{itemize}
	\item fixed transmission range for every node 10m (bluethoot), which implies that the broadcast area of each node is 314.15$m^2$
	\item total number of participants: 2K nodes where 1.5K at dense region and 0.5 at sparse region; such number of participants implies:
	\begin{itemize}
		\item $\frac{\text{DenseArea}}{\text{NodesAtArea}} = 0.83m^{2}/\text{node}$, this means that every node is separated at most $ \sqrt{83} = 9.11\text{cm}$ from each other at PoI
		\item $\frac{\text{SparseArea}}{\text{NodesAtArea}} = \frac{2800}{500} = 5.4m^{2}/\text{node}$, this means that every node is separated at most $ \sqrt{5.4} = 2.32\text{m} $ from each other at sparse region
		\item Tx$=10$ implies that every node have at least $\frac{BroadcastArea}{AreaPerNode} = \frac{314.15m^{2}}{0.83m^{2}/\text{node}} = 378$ neighbors in dense area
		\item similarly, every node have at least $ \frac{314.15m^{2}}{5.4m^{2}/\text{node}} = 58$ neighbors in sparse area
	\end{itemize}
	\item duration of experiment 10 minutes	
	\item data frame interval: 1s (600 broadcast sessions)
	\item control frame interval: 5s (120 messages) , 15s (40 messages) or 25s (24 messages) (this may vary depending on how MPR maintains a robust overlay)

\end{enumerate}

\textbf{broadcast metrics}
\begin{itemize}
	\item power consumption
	\item coverage
	\item rebroadcast: comparison of number of transmissions of data frames with pure flooding
	\item sent/received data frames
	\item data frame error rate: number of not heard ACKs at mac layer over all data frames; this is our way of measure collisions
\end{itemize}

\er{
Goal for this section: show experimentally that the proposed algorithms and protocols answer the research questions set forth in the introduction.
We aim at answering the following research questions:
\begin{itemize}
	\item Does the use of a single protocol in an heterogeneously distributed MANET lead to sub-optimal performance?
	\item Is it beneficial to use different protocols for broadcast in a heterogeneously-distributed MANET, and does it reduce contention/collisions, costs, and improves overall reliability?
	\item What is the relative impact of heterogeneity in motion, and heterogeneity in placement, to the difference in performance and reliability observed in the complete MANET?
	\item What is the cost of the interoperability mechanism when a subset of the network decides to adapt and emerge an overlay in its region?
	\item Are the observables available locally to each node a good representation of the actual deployment environment of each node?
	\item How effective are the adaptation strategies in autonomously deciding on the emergence of overlays or the use of flooding-based broadcast?
\end{itemize}
The section can be structured as follows:
\begin{itemize}
	\item Experimental setup: simulator, traces, models for the nodes energy consumption, etc.
	\item Recap that we use our MAC layer
	\item Microbenchmarks with the square setup
	\item Macrobenchmarks with more complex setups, with different dense/dynamic regions over space
\end{itemize}
