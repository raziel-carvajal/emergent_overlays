\begin{itemize}
	\item we follow a main switching criterion: nodes in dense areas maintain a dissemination overlay and nodes in sparse areas broadcast via a controlled flooding technique \er{this should have been said in the previous section, not here}\raziel{not even as a recap of previous section?}
	
	\item our interoperability mechanism ensures continuity in the delivery of messages despite the fact that nodes at regions with different densities use different protocols
	
	\item messages are delivered to every node that is part of the wireless topology when source nodes:
		\begin{enumerate}
		\item are part of a dissemination overlay, or
		\item use controlled flooding
	\end{enumerate}

	\item interoperability issues: we show that messages may be lost when nodes run different protocols in the same network as shown in figure~\ref{fig:interop-example}
	\begin{enumerate}
		\item \textbf{Case: transit of messages from sparse to dense region}
		\begin{itemize}
			\item node $t_{4}, t_{5}$ are in the range of $f_{1}$
			\item $f_{1}$ receives a message from $f_{2}$
			\item threshold of retransmission is reached at $f_{1}$
			\item $t_{4}, t_{5}$ do not receive message
		\end{itemize}
		
		\item \textbf{Case:transit of messages from dense to sparse region}
		\begin{itemize}
			\item nodes $t_{6}$ is in the range of $f_{3}$
			\item $t_{6}$ receives a message from $t_{3}$
			\item $t_{6}$ doesn't forward due to its role in the overlay
			\item $f_{3}$ do not receive message
		\end{itemize}
	\end{enumerate}
	
	\item we need that nodes be aware when they are located at the frontier of regions that run different algorithms; we call them border nodes
	
	\item assume that nodes are aware of being at the frontier of regions and they tag themselves as border nodes
	
	\item \textbf{Case: transit of messages from sparse to dense.} Border node $f_{1}$ in figure~\ref{fig:interop-example} is border node and it forwards only once a message when its threshold of retransmissions have been reached
	
	\item \textbf{Case: transit of messages from dense to sparse region.} Border node $t_{6}$ forwards a message using controlled flooding. This action requires a change in the package to avoid a change in the dissemination overlay
	
	\item transit of messages between zones is performed via border nodes (interoperability works)
	
	\item border detector mechanism \raziel{sketch of algorithm, but find it in appendix}
