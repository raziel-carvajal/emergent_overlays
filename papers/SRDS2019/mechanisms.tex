We revisit the issues and opportunities of broadcast in a situation where disjoint clusters of nodes follow either, a controlled flooding approach or an overlay-based one.
%
We propose an interoperability mechanism that ensures continuity in the delivery of messages independently of the protocol running at each node.

\subsection{Interoperability issues}
\label{sec:mechanisms:interop-issues}
In the general case, a system where nodes of a disjoint cluster in the network run a certain protocol, may result in any interaction with other participants.
%
The combination of two protocols to broadcast in MANETs, controlled flooding and overlay-base, may avoid the delivery of frames coming from any source in the network.
%
In our vision of emergent overlays (Figure~\ref{fig:general_principle}), nodes in clusters maintain an overlay.
%
Even if there are nodes out of the cluster that are in range to receive frames, such nodes do not reply back because such messages are unknown to them.
%
Nodes participating in a dissemination overlay are limited by the frontier of clusters, therefore, data frames are not delivered to nodes running controlled flooding.

\subsection{Interoperable relays}
\label{sec:mechanisms:interop-relays}

To assure that data frames or \emph{messages} transit between adjacent clusters of nodes running different algorithms, nodes must figure out when they are located at the frontier of such clusters.
%
We call such nodes \emph{interoperable relays} \er{rather interoperability relays, or border relays?} and give a proof that these relays enforce broadcast by covering nodes of every adjacent cluster in a MANET.
%
First, we formalize the system model we present in section~\ref{sec:background:model}.

%
We define a network as an undirected graph $ G = (N, L, P) $ where $ N = \{ n_{i} \mid i \in 1, \dots, m \} $ is the set nodes, $ L = \{ (n_{i}, n_{j}) \mid n_{i}, n_{j} \in N, i \neq j, (n_{i}, n_{j}) = (n_{j}, n_{i}) \} $ is the set of links, and $ P = \{p_{\text{flood}}, p_{\text{cds}} \} $ is a set of broadcast protocols.

$P$ contains only two elements, $p_{\text{flood}}$ represents a controlled flooding approach and $p_{\text{cds}}$ an overlay-based one.
%
A disjoint component in such graph, where its nodes use a single protocol (within that component), is a set of nodes $ C_{k, p} \subset N $ such that $\bigcup\limits_{k \; \in \; 1 \dots c} C_{k, p} = N $ with $ c > 2 $ and $ p \in P $.

\begin{definition}
The set of interoperable relays $ I = \{ (n_{i}, n_{j}) \in N \mid n_{i} \ominus n_{j}, (n_{i}, n_{j}) \in L \} $ are all pair of nodes that are in range and follow the relation $\ominus$.
\end{definition}
%
\begin{theorem}
Let $ n_{i}, n_{j} $ be two interoperable relays and a source $s$ located at any of the components of $ n_{i} $ or $ n_{j} $.
%
If both interoperable relays forward a received message from $s$ at least once, then such message is delivered to every node in the components of $ n_{i} $ and $ n_{j} $.
\end{theorem}
%
We recall one property for each protocol in $P$ that we use in the proof of Theorem 1.
%
Nodes running $p_{\text{flood}}$ forward incoming messages only if a threshold $t$ haven't been reached
%
For instance, $t$ may be the number of received copies ~\cite{BroadcastStormProblem}.
%
On the other hand, every node running $p_{\text{cds}}$ is adjacent to at least one overlay relay, which is a property of a Connected Dominating Set (CDS)~\cite{cds-explained}.
%
\begin{proof}
Randomly select $ n_{i}, n_{j} $ and decide that $n_i$ follows a controlled flooding approach and $n_j$ maintains a dissemination overlay.
%
The proof is still valid when we decide that $n_i$ runs $p_{\text{cds}}$ and $n_j$ runs $p_{\text{flood}}$ because, the relation $\ominus$ is reflexive.
%
Let $ C_{k, p_{\text{flood}}} $ and $ C_{l, p_{\text{cds}}} $ be the disjoint components of $n_i$ and  $n_j$, respectively.
%
We separate the proof in two cases, the first case deals with the situation where any interoperable relay is a source node.
%
In the second case, proved by contradiction, the source node is at any of both components.

%
\textbf{Case 1}. We consider that $n_i$ is a source for message $m$.
%
On reception of $m$ by any surrounding of $n_i$ running controlled flooding, results in the delivery of such message by every node in $ C_{k, p_{\text{flood}}} $.
%
$n_j$ is also a surrounding of $n_i$, when $n_j$ forwards $m$ it is received by at least one of its adjacent overlay relays.
%
Therefore all overlay relays forward $m$ and such message is received to every node in $ C_{l, p_{\text{cds}}} $
%

%
\textbf{Case 2.} We now consider that $ s \in C_{l, p_{\text{cds}}} $ is a source of $m$.
%
Eventually $n_{j}$ receives $m$, $n_{j}$ forwards $m$ to $n_{i}$ and the latter node forwards such message as well.
%
Let $n_{h} \in C_{k, p_{\text{flood}}} $ be a node adjacent to $n_{i}$ that do not retransmit $m$.
%
This situation will result in having at least one other node that do not hear from $m$, which is a negation of the \emph{to every} statement in Theorem 1.
%
%
In other words $n_{h}$ reach its threshold, that is a contradiction, because it received $m$ from $n_i$ for the first time.
%
Without loss of generality, assume that $ s \in C_{l, p_{\text{flood}}} $ and $n_j$ receives $m$ from $n_i$.
%
Once $n_j$ forwards $m$ the overlay relay adjacent to $n_j$, such relay disseminates the message.
%
Assume that there is a node $n_{h} \in C_{l, p_{\text{cds}}} $ that do not receive $m$, which implies that $n_h$ is not connected to any relay node.
%
This a contradiction, because a CDS is a connected component.
%
We then conclude that every node in both components receive $m$ at least once when the source is located at $ C_{k, p_{\text{flood}}} $ or $ C_{l, p_{\text{flood}}}$.
\end{proof}
