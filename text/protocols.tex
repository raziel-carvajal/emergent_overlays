\subsection*{Topology-free protocols}
We discuss in Section~\ref{sec:background} how some protocols do not require to build an underlying topology.
The canonical algorithms with this property is \textit{blind flooding}, in where a node retransmits a message upon receiving for the first time.
However, we are interested in more efficient protocols.

In~\cite{Ovalle-Martinez2006}, the authors present the \textit{Area-based beaconles protocol} (ABBA).
This is an algorithm where the flooding process is controlled in both space and time.
Notice that the algorithm requires that each node knows its physical location as well as the transmission radio of each node.
Upon the reception of a message, a node first computes the angle $\alpha$ covered by the received transmission.
Using this information it then schedules a timer with a timeout $T = T_\textit{max} - T_\textit{max}\frac{\alpha}{2\pi}$, where $T_\textit{max}$ is the maximum waiting time.
If the same message is received before the timer expires, the node updates $\alpha$, cancels the previous timer and creates a new one.
No retransmission occurs if at some point the angle $\alpha$ covers the complete area around a node.
When a timer expires, the message is retransmitted by the node.

\subsection*{CDS-based protocols}

A connected dominating set of a graph G is a set D of vertices with two properties:

\begin{enumerate}
	\item Any node in D can reach any other node in D by a path that stays entirely within D.
	\item Every vertex in G either belongs to D or is adjacent to a vertex in D.
\end{enumerate}

In MANETs, several protocols use the CDS rule to drive the broadcasting process.
It states that a node retransmits a message once and only once if it belongs to the CDS.
In an attempt to reduce resource consumption, and given the fact that the problem is NP, many protocols use a distributed and heuristic-based approach to compute an approximation of the \textbf{minimum connected dominating set}.
As part of this paper, we have implemented two CDS-based protocols.

The first approach we implement is the well-know \textit{Multipoint Relays Set (MPR)}~\cite{Qayyum2002}.
In this protocol, each node computes its own set of multipoint relays.
To do so, information regarding the 1-hop and 2-hops neighbors is required; hence, \textit{HELLO} messages containing such data are periodically sent.
When a \textit{relay} node $n$ receives a messages, it computes its own multipoints relays ($\textit{MPR}(n)$), attaches it to the message and retransmits it to its neighbors.
Then, a neighbor of $n$ retransmits the message if it belongs to $\textit{MPR}(n)$.
This kind of strategy where the relays are selected during the broadcasting process is \textit{source-dependent}.


\begin{enumerate}
	\item A node $w$ is in $MPR(v)$ if it is the only member of $N(v)$ that is neighbor of some node in $N^2(v)$.
	\item While there exists a node $w \in N^2(v)$ which is not covered by a node in $MPR(v)$: select the node $z \in N(v)$, but not in $MPR(v)$, that covers more uncovered nodes in $N^2(v)$. Add $w$ to $MPR(v)$.
\end{enumerate}


Wu et al. propose \textit{node-degree-based} rules to reduce the size of the connected dominating set~\cite{Wu2001}. Observe that to broadcast a message it is not necessary to apply all rules -- rule 1 is enough. Notice that in the definition of such rules $\textit{nd}(v)$ is the node degree of $v$, $\textit{id}(v)$ is an unique identifier assigned to $v$ and $N\left[v\right] = N(v) \cup \lbrace v \rbrace$. The rules proceed as follows:

\begin{enumerate}
	\item A node is marked if it has two unconnected neighbors. That is, $\exists u, w \in N(v), u \notin N(w)  \quad \textit{and} \quad w \notin N(w)$.
	\item Consider two marked vertices $v$ and $u$. Then, $v$ is unmarked if one of the following conditions holds:
	\begin{itemize}
		\item $N\left[v\right] \subseteq N\left[u\right] \quad \textit{and} \quad \textit{nd}(v) < \textit{nd}(u)$.
		\item $N\left[v\right] \subseteq N\left[u\right] \quad \textit{and} \quad \textit{nd}(v) = \textit{nd}(u) \quad \textit{and} \quad \\ \textit{id}(v) < \textit{id}(u)$.
	\end{itemize}
	
\end{enumerate}
