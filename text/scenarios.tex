\section{Experimental Scenario}
\label{sec:scenarios}
\changed{
%
Our experimental scenarios are built considering three variables found in MANETs: power consumption of mobile devices, message dissemination while nodes move or remain static and construction of networks of nodes.
%
Our inspiration came from a real life scenario: \textit{protest march}, where these three variables take place, people uses their mobile phones to communicate and message dissemination to all participants is critical.
%
Furthermore, we are interested in proposing a benchmark to evaluate the performance of broadcasting protocols.
%
More details about the broadcasting metrics we chose are given in section \ref{sec:evaluation}.
}

\subsection*{Power consumption}
\changed{
Efficient utilization of energy in wireless communication must be taken into consideration and power consumption highly depends on the Wi-Fi chip used by mobile devices.
%
We chose the power consumption model of the chip Broadcom BCM4329, which is found in modern mobile devices, Table~\ref{tbl:wifi-chip} shows the amount of Watts that this chip requires in its different modes.
%
Additionally, this chip supports the protocol Wi-Fi 802.11g on the 2.4 GHz band~\cite{BCM4329}.
}

To simulate this chip, we use the \textit{StateBasedEnergyConsumer} model provided by INET.
%
This model measures how many Joules were consumed based on the time the chip spends on each mode (as described in Table~\ref{tbl:wifi-chip}).
%
Formally, this energy consumption model uses three functions: $c : M \mapsto \mathbb{R} $, $r_m: \mathbb{R} \mapsto M$ and $t_m: \mathbb{R} \mapsto M$ where $M$ is the set of operation modes of the chip, $c$ is the consumption of the chip on each mode, and functions $r_m, t_m$ map from simulation time to operational modes of the \textit{receiver} and \textit{transceiver}, respectively.
%
INET then computes the energy consumption with the integral equation as follows:  $C(t)=\int_{0}^{t_\textit{simulation}} (r_m \circ c) (t) + (t_m \circ c) (t) \textit{dt}$. Function $m$ is given and INET computes both $r_m$ and $t_m$ during the simulation.


\subsection*{
\changed{Network Construction through Disk Graphs}
}
%
\changed{
Disk graphs are used to model the positioning of random points uniformly distributed in the plane, offering the reflexive property $C$ (read as \textit{is close to}) among the vertex of such a graph. If $\{v_{a}, v_{b}, v_{c}\}$ is a set of vertex in a disk graph and $v_{a} C v_{b}$, $v_{b} C v_{c}$ are both true then, $v_{a} C v_{c}$ is true as well.
%
$C$ is a fundamental property that models realistic scenarios~\cite{Penrose2003}, more importantly, it allows us to build wireless networks with density $d$ following the formula $d=\pi nr^{2}$ where $r$ refers to the communication range of nodes and $n$ is the total number of nodes.

\subsection*{
\changed{Mobility Model of Nodes}
}
\changed{
Mobility of nodes in our simulations follow a Levy Walk (LW) model to characterize routing performance of networks where humans carry mobile devices~\cite{Rhee:2011}.
%
This truncated LW model approximates how humans move (frequent short walks and occasional long rides to distant locations) and does not take into account obstacles, i. e., when there is an obstacle for every pair of movements, these movements are linked.
%
The authors of this study stated that unique performance characteristics were found for MANETs but they do not report these results.
